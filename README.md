Electric Vehicle Market Performance & Insights

Project Overview

This project explores the Electric Vehicle (EV) market using interactive Tableau dashboards and visualizations. It analyzes EV records, vehicle categories, manufacturers, battery technologies, customer ratings, annual sales trends, and global manufacturing distribution.

The project uses a dataset containing 100,000 EV records and presents key insights through an interactive dashboard and a five-point Tableau Story.

Dashboard Features

- EV Market Performance overview
- EV Category Performance and Distribution
- Top Manufacturers comparison
- Customer Rating analysis
- Annual EV Sales Trend
- Battery Technology Market Share
- EV Distribution by Country
- Driving Range vs Price analysis
- Battery Capacity and Efficiency analysis

Interactive Filters

The dashboard includes five interactive filters:

- Manufacturer
- Category
- Manufacturing Country
- Model Year
- Battery Type

These filters allow users to explore different segments of the EV market.

Tableau Story

The project includes a five-point story titled Global Electric Vehicle Market Story:

1. EV Market Snapshot
2. Category Performance
3. Manufacturer Landscape
4. Battery Technology Mix
5. Global Manufacturing Footprint

How to Use

1. Download the Tableau ".twbx" workbook.
2. Open Tableau Public.
3. Select File → Open.
4. Open the downloaded workbook.
5. Explore the dashboard and its interactive filters.
6. Navigate to the EV MARKET STORY tab to view the five story points.
